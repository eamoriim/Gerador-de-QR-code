# 📱 Gerador de QR Code em Python

Aplicação simples desenvolvida em Python para geração automática de imagens de QR Code a partir de links ou textos.

---

## 🛠️ Tecnologias Utilizadas

* **Python** (versão 3.12+)
* **[uv](https://astral.sh/uv)** - Gerenciador de pacotes e ambientes virtuais
* **`qrcode[pil]`** - Biblioteca para geração e renderização de imagens QR Code

---

## 🚀 Como Executar o Projeto

### Pré-requisitos
Certifique-se de ter o **`uv`** instalado no seu sistema.

### Garanta o pip na .venv

* python -m ensurepip --upgrade
* python -m pip install qrcode
